# Frontend

React, TypeScript and Vite serve GroceryGenie’s customer, seller and assistant pages. The liquid-glass theme is built into the app styles. Vite forwards API and upload requests to the local backend, and nginx does so for Compose.

From this directory run `npm ci`, then `npm run dev` for development or `npm run build` for the linted, type-checked production bundle. For setup, authorization and Chromium tests, see the [project README](../README.md).
